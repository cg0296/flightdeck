6. SUPERVISOR SPAWN LOGIC: POST /api/supervisor/launch:
- Reads the supervisor config
- Spawns a supervisor Claude process that:
  - Reads the master plan (sub_agents array)
  - Spawns sub-agents as child Claude CLI processes based on order and depends_on
  - Monitors each sub-agent by watching their JSONL files and PROGRESS.md
  - When a sub-agent finishes (process exits), checks depends_on to see if next agent should launch
  - Updates FlightDeck via internal API calls (POST /api/transponder/ping)
  - On completion of all sub-agents, sends final report

7. SUB-AGENT LIFECYCLE TRACKING: New SQLite table:
```sql
CREATE TABLE sortie (
  id TEXT PRIMARY KEY,
  supervisor_config_id TEXT,
  name TEXT,
  status TEXT DEFAULT 'active', -- active, completed, failed, aborted
  started_at TEXT,
  ended_at TEXT,
  total_cost REAL DEFAULT 0,
  FOREIGN KEY (supervisor_config_id) REFERENCES supervisor_config(id)
);

CREATE TABLE sortie_agent (
  id TEXT PRIMARY KEY,
  sortie_id TEXT,
  agent_name TEXT,
  cwd TEXT,
  prompt TEXT,
  model TEXT,
  pid INTEGER,
  session_id TEXT,
  status TEXT DEFAULT 'queued', -- queued, launched, running, landed, mayday
  order_index INTEGER,
  depends_on TEXT, -- JSON array of agent names
  started_at TEXT,
  ended_at TEXT,
  tokens_used INTEGER DEFAULT 0,
  estimated_cost REAL DEFAULT 0,
  exit_code INTEGER,
  output_summary TEXT,
  FOREIGN KEY (sortie_id) REFERENCES sortie(id)
);
```
